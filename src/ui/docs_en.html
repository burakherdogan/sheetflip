Documentation

Enter any whole number from 1 to 100 for pages per side. The preview updates automatically. Multiple pages are placed onto A4 sheets by the application; unused cells remain blank. Booklets always use 2 pages per side.

Sheetflip is a small web app for printing PDFs on printers without automatic duplex. It prints the fronts, tells you how to reload the paper, then prints the backs in the right order. It also imposes A5 booklets.

Layouts

  • Single-sided: a normal print job.
  • Double-sided: fronts first, then backs after you reload the stack. Odd page counts get a blank last back so copies stay aligned.
  • Booklet: two pages per side, ordered so the stack can be folded into an A5 booklet. Blank pages are added up to a multiple of four.

The preview shows every sheet with its front and back before anything is sent to the printer.

Install

Requirements: Linux or macOS with CUPS, the lp and lpstat commands, and at least one printer added in CUPS.

Download the binary from the releases page, or build it with Rust:

cargo build --release
./target/release/sheetflip

Open http://localhost:8080. The binary contains the whole interface; no other files are needed.

Configuration

Settings are environment variables. Printer test results are stored in ~/.config/sheetflip/printers.json.

LISTENAddress to listen on. Default 0.0.0.0:8080.
DATA_DIRWhere uploaded files are kept while a job runs. Default: system temp directory.

Run as a service

With systemd, as your own user. No root needed:

# ~/.config/systemd/user/sheetflip.service
[Unit]
Description=Sheetflip

[Service]
ExecStart=%h/.local/bin/sheetflip
Restart=on-failure

[Install]
WantedBy=default.target
systemctl --user enable --now sheetflip

Printer test

Printers feed and stack paper differently. Before the first double-sided print, run the printer test once for each printer:

  1. Choose the printer and print the test page. Two sheets are used.
  2. Reload the paper as shown on screen and print the backs.
  3. Answer two questions: which number is on the back of sheet 1, and whether the arrow on the back points up.

The answers are saved for that printer in ~/.config/sheetflip/printers.json. Double-sided and booklet prints use them from then on. Run the test again if you change how you reload the paper.

Privacy & security

  • Files never leave this computer. They are sent only to the local CUPS server.
  • Files are deleted when a job finishes. Unfinished jobs are removed after 24 hours.
  • There is no login. Anyone who can reach the address can print. To allow only this computer, use LISTEN=127.0.0.1:8080.

Troubleshooting

“No printers found”
Add the printer in CUPS (http://localhost:631) and check that lpstat -e lists it.
Nothing comes out
Open http://localhost:631/jobs to see whether the job is waiting or stopped.
Backs on the wrong sheets or upside down
Run the printer test again and reload the paper exactly as shown.
The preview is empty
The PDF may be encrypted or damaged. Try exporting it again.

PDF preview uses PDF.js (Apache-2.0).
